Cài đặt
URL của Bridge Server (chạy cùng tool Veo3 Ultra).
Mặc định: ws://127.0.0.1:3000/ws — không cần thay đổi nếu tool chạy cùng máy.
Tên hiển thị trong log. Hữu ích khi nhiều máy cùng kết nối.
Khi được bật: nếu không tìm thấy tab labs.google nào đang mở, extension tự mở tab mới.
Tắt nếu bạn muốn tự kiểm soát tab nào được dùng.
Hướng dẫn sử dụng
1
Chạy tool Veo3 Ultra — Bridge Server tự start tại ws://127.0.0.1:3000/ws
2
Mở https://labs.google/fx/tools/flow trong Chrome và đảm bảo đã đăng nhập Google
3
Extension kết nối WS (đèn xanh) — popup hiển thị "✓ 1 tab labs.google"
4
Trong tool, set RECAPTCHA_SOURCE=extension hoặc chọn Extension Bridge mode
5
Token được lấy từ tab thật của user → trust score cao nhất, không bị 403
